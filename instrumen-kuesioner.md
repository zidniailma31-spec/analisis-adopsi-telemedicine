# Instrumen Penelitian: Kuesioner Adopsi Telemedicine

## Digital Health Literacy (X1)

| Kode | Indikator | Pernyataan |
|---|---|---|
| DHL1 | Mencari informasi kesehatan digital | Saya mampu mencari informasi kesehatan melalui internet atau media digital. |
| DHL2 | Menemukan informasi relevan | Saya mampu menemukan informasi kesehatan digital yang sesuai dengan kebutuhan saya. |
| DHL3 | Memahami informasi digital | Saya mampu memahami informasi kesehatan yang saya peroleh melalui media digital. |
| DHL4 | Menilai kredibilitas informasi | Saya mampu menilai apakah informasi kesehatan yang saya temukan di internet dapat dipercaya. |
| DHL5 | Memanfaatkan informasi kesehatan | Saya mampu menggunakan informasi kesehatan digital sebagai bahan pertimbangan keputusan terkait kesehatan. |

## Self-Efficacy (X2)

| Kode | Indikator | Pernyataan |
|---|---|---|
| SE1 | Keyakinan mengakses telemedicine | Saya yakin mampu mengakses layanan telemedicine ketika membutuhkannya. |
| SE2 | Keyakinan mengoperasikan fitur | Saya yakin mampu mengoperasikan fitur-fitur dalam aplikasi telemedicine. |
| SE3 | Keyakinan menjalani konsultasi | Saya yakin mampu menjalani proses konsultasi kesehatan melalui telemedicine. |
| SE4 | Penggunaan mandiri | Saya yakin mampu menggunakan telemedicine tanpa bantuan orang lain. |
| SE5 | Mengatasi kendala teknis | Saya yakin mampu mengatasi kesulitan teknis sederhana saat menggunakan telemedicine. |

## Perceived Benefit (X3)

| Kode | Indikator | Pernyataan |
|---|---|---|
| PB1 | Kemudahan akses | Menurut saya, telemedicine mempermudah akses terhadap layanan kesehatan. |
| PB2 | Penghematan waktu | Menurut saya, telemedicine dapat menghemat waktu untuk memperoleh layanan kesehatan. |
| PB3 | Pengurangan biaya transportasi | Menurut saya, telemedicine dapat mengurangi biaya transportasi untuk memperoleh layanan kesehatan. |
| PB4 | Kemudahan konsultasi | Menurut saya, telemedicine mempermudah proses konsultasi dengan tenaga kesehatan. |
| PB5 | Manfaat bagi kebutuhan kesehatan | Menurut saya, telemedicine bermanfaat untuk membantu memenuhi kebutuhan konsultasi kesehatan. |

## Adoption Telemedicine (Y)

| Kode | Indikator | Pernyataan |
|---|---|---|
| AT1 | Niat menggunakan | Saya berniat menggunakan telemedicine ketika membutuhkan konsultasi kesehatan. |
| AT2 | Kesediaan menggunakan | Saya bersedia menggunakan telemedicine sebagai salah satu alternatif layanan kesehatan. |
| AT3 | Rencana penggunaan masa depan | Saya berencana menggunakan telemedicine pada masa mendatang ketika membutuhkan layanan kesehatan. |
| AT4 | Pertimbangan memilih layanan | Saya akan mempertimbangkan telemedicine ketika sesuai dengan kebutuhan konsultasi saya. |
| AT5 | Niat melanjutkan penggunaan | Saya berniat terus menggunakan telemedicine apabila sesuai dengan kebutuhan kesehatan saya. |

Skor setiap variabel adalah rata-rata dari lima pernyataannya, dengan rentang 1–5.
